# Tally Product Import Integration

This document outlines the CSV import functionality designed specifically to handle exports from Tally ERP (or generic spreadsheets).

## Overview
The platform allows store admins to seamlessly import products, stock levels, and pricing directly via a CSV file upload. The backend uses intelligent column mapping to interpret headers typically generated by Tally's "Item Export" or "Closing Balance" reports.

## Supported Column Headers

The importer scans the first row (header) of the CSV file and dynamically maps columns to the product schema. The matching is case-insensitive.

| System Field | Recognized Tally/CSV Headers (Any of these) | Required | Description |
| :--- | :--- | :---: | :--- |
| **Title/Name** | `title`, `name`, `item name`, `product name` | Yes | The name of the product. Used to find existing products or create new ones. |
| **Price** | `price`, `rate`, `standard price`, `mrp` | Yes | The base selling price of the item. Automatically strips currency symbols. |
| **SKU** | `sku`, `part no`, `alias`, `item code` | No | A unique identifier for the product variant. If omitted, the system generates a slugified version of the title. |
| **Stock** | `stock`, `qty`, `closing balance`, `quantity` | No | Available inventory count. Defaults to `0` if omitted. |

> [!NOTE]
> The importer requires at least the **Name** and **Price** columns to be present and recognized in the CSV file. If neither is found, the import will abort and return a validation error.

## Daily Stock & Price Updates (Re-uploading)
The import system is designed to handle continuous uploads (e.g., daily stock updates from Tally) without duplicating your primary products.

- **Product Matching**: The system searches for an existing product based on the **Title**. If it exists, it updates it; if not, it creates a new one.
- **Stock/Price Updating (Variant Level)**: The system updates the price and stock based on the **SKU**. 

> [!WARNING]
> **SKU Requirement for Daily Updates:** If you plan to upload CSV files daily to update stock, your CSV **MUST** include a consistent SKU (e.g. `Item Code`, `Part No`, or `Alias`). If the SKU column is missing, the system generates a random SKU (e.g., `apple-123`) on the first upload. Subsequent uploads without an SKU will generate a *new* random SKU, creating duplicate variants instead of updating the existing stock!

## Import Workflow (`Admin/ProductController@import`)

1. **Upload Validation**: The system verifies the uploaded file is a valid `.csv` or `.txt` format and under 10MB in size.
2. **Header Resolution**: The system parses the first row, converts it to lowercase, and assigns the correct index for Title, SKU, Price, and Stock based on the Tally-to-System Mapping array.
3. **Data Sanitization**:
   - `Price` strips all non-numeric characters except decimals (e.g., "Rs. 1,500.50" becomes `1500.50`).
   - `Stock` strips all non-numeric characters (e.g., "50 pcs" becomes `50`).
4. **Database Transaction**:
   - The importer loops through each row.
   - It performs a `firstOrCreate` on the `products` table matching the exact `title` within the current active `tenant_id`.
   - It then creates a new `ProductVariant` for that product containing the `sku`, `price`, and `stock`.
5. **Completion**: If successful, the transaction is committed, and the admin is redirected with a success flash message indicating the number of products imported. If any database error occurs, the transaction rolls back safely.

## Usage Guide for Admins
1. Export the "Stock Item" or "Closing Balance" report from Tally into an Excel format.
2. Ensure headers align with one of the accepted keywords above (e.g., change "Particulars" to "Item Name" if needed).
3. Save the Excel file as a **CSV (Comma delimited)** file.
4. Navigate to the Products page in the Admin Panel.
5. Use the "Import Products" modal to upload the CSV file.
